# University Cafeteria Supply Management System

A simple ASP.NET Core MVC project built with Razor views, arrays, loops, conditionals, layouts, and Bootstrap.

## Run

Open `UniversityCafeteria/UniversityCafeteria.csproj` in Visual Studio and run the project, or use:

```bash
dotnet run --project UniversityCafeteria/UniversityCafeteria.csproj
```

Pages:

- `/Cafeteria/Index`
- `/Cafeteria/Products`
- `/Cafeteria/Suppliers`
- `/Cafeteria/SupplyStatus`
